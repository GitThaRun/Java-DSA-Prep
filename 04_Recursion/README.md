# Recursion

This folder contains my **Recursion** problems and solutions as part of my Java DSA Journey.

## Objective

The goal of this section is to build a strong understanding of recursion and learn how to identify, design, and optimize recursive solutions for coding interviews.

## Topics Covered

* Recursion Basics
* Base Case and Recursive Case
* Recursive Tree
* Stack Space
* Tail Recursion
* Multiple Recursion Calls
* Recursion on Arrays
* Recursion on Strings
* Recursion with Backtracking
* Subsets and Subsequences
* Permutations
* Combination Problems
* Divide and Conquer
* Recursion-Based Searching and Sorting
* Common Interview Problems

## Problem-Solving Approach

For each problem, focus on:

1. Identifying the **base case**.
2. Defining the **recursive case**.
3. Understanding what each recursive call represents.
4. Tracking the **call stack**.
5. Analyzing time and space complexity.
6. Converting recursive solutions to iterative solutions where relevant.

## Folder Structure

Each problem generally contains:

* Java solution
* Time Complexity
* Space Complexity
* Explanation or dry run where necessary

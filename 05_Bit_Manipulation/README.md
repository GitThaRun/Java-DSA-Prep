# Bit Manipulation

This folder contains my **Bit Manipulation** problems and solutions as part of my Java DSA Journey.

## Objective

The goal of this section is to understand how numbers are represented and manipulated at the bit level, and to apply bitwise techniques to solve coding problems efficiently.

## Topics Covered

* Binary Representation
* Bitwise AND (`&`)
* Bitwise OR (`|`)
* Bitwise XOR (`^`)
* Bitwise NOT (`~`)
* Left Shift (`<<`)
* Right Shift (`>>`)
* Unsigned Right Shift (`>>>`)
* Check if a Number is Odd or Even
* Check / Set / Clear / Toggle a Bit
* Count Set Bits
* Power of 2
* Find the Single Number
* XOR-Based Problems
* Swap Numbers Using XOR
* Remove the Last Set Bit
* Find the Rightmost Set Bit
* Subsets Using Bit Manipulation
* Bit Masking
* Common Interview Problems

## Problem-Solving Approach

For each problem, focus on:

1. Understanding the binary representation.
2. Identifying the relevant bitwise operation.
3. Deriving the solution instead of memorizing the trick.
4. Checking edge cases involving `0`, negative numbers, and integer limits.
5. Analyzing time and space complexity.

## Folder Structure

Each problem generally contains:

* Java solution
* Time Complexity
* Space Complexity
* Explanation or dry run where necessary

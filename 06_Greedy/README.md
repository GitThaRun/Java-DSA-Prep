# Greedy Algorithms

This repository contains Java implementations of **Greedy Algorithm** problems commonly encountered in coding interviews, competitive programming, and technical placements.

The goal is to understand how greedy strategies work by solving problems that require making the best possible local choice at each step to achieve an optimal solution.

## Objective

To improve algorithmic thinking, recognize greedy patterns, and prepare for coding interviews and technical placement assessments.

## Topics Covered

* Sorting-based greedy algorithms
* Activity selection
* Interval scheduling
* Fractional Knapsack
* Job sequencing
* Two-pointer greedy techniques
* Resource allocation
* Optimization problems


## Problem-Solving Approach

For each problem, the implementation focuses on:

1. Understanding the problem constraints.
2. Identifying the greedy choice.
3. Selecting an appropriate sorting or traversal strategy.
4. Implementing the solution in Java.
5. Analyzing time and space complexity.

## Folder Structure

Each problem generally contains:

* Java solution
* Time Complexity
* Space Complexity

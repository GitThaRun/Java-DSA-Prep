# Stack

This repository contains **Java implementations of Stack data structures and Stack-based problems** commonly encountered in coding interviews, competitive programming, and technical placements.

The focus is on understanding the LIFO (Last In, First Out) principle, implementing stack operations, and applying stack-based techniques to solve problems efficiently.

## Topics Covered

- Stack Fundamentals
- Stack Implementation Using Arrays
- Stack Implementation Using Linked Lists
- Stack Implementation Using Collections
- Push, Pop, Peek Operations
- Balanced Parentheses
- Infix, Prefix, and Postfix Expressions
- Next Greater Element
- Next Smaller Element
- Monotonic Stack
- Stock Span Problem
- Largest Rectangle in Histogram
- Recursive Stack Problems

## Problem-Solving Approach

For each problem, the implementation focuses on:

1. Understanding the LIFO principle.
2. Identifying when a stack is the appropriate data structure.
3. Understanding the push and pop operations involved.
4. Implementing an efficient Java solution.
5. Analyzing time and space complexity.

## Technologies Used

- Java
- Arrays
- Linked Lists
- Java Collections Framework
- Monotonic Stack

## Objective

To develop a strong understanding of Stack data structures, recognize stack-based problem-solving patterns, and solve interview-level problems independently.
